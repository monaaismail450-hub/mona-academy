# 📱 منى الأكاديمي - دليل التثبيت

## الملفات المطلوبة
- index.html  ← التطبيق الرئيسي
- manifest.json ← معلومات التطبيق
- sw.js ← يجعله يعمل بدون إنترنت
- icon-192.svg ← أيقونة صغيرة
- icon-512.svg ← أيقونة كبيرة

---

## 🚀 خطوات نشر التطبيق مجاناً (GitHub Pages)

### الخطوة 1 - إنشاء حساب GitHub
- روحي على github.com وسجّلي حساب جديد مجاني

### الخطوة 2 - إنشاء مستودع جديد
- اضغطي "New Repository"
- سمّيه: mona-academic
- اتركيه Public
- اضغطي "Create Repository"

### الخطوة 3 - رفع الملفات
- اضغطي "uploading an existing file"
- ارفعي جميع الملفات الخمسة
- اضغطي "Commit changes"

### الخطوة 4 - تفعيل GitHub Pages
- اذهبي إلى Settings ← Pages
- اختاري Branch: main
- اضغطي Save

### الخطوة 5 - رابط التطبيق
بعد دقيقتين، رابطك سيكون:
https://اسمك.github.io/mona-academic/

## 📲 تثبيت على الجوال

### آيفون (Safari):
1. افتحي الرابط في Safari
2. اضغطي زر المشاركة ⬆️
3. اختاري "إضافة إلى الشاشة الرئيسية"
4. اضغطي "إضافة"

### أندرويد (Chrome):
1. افتحي الرابط في Chrome
2. اضغطي ثلاث نقاط ⋮
3. اختاري "إضافة إلى الشاشة الرئيسية"
4. اضغطي "إضافة"
